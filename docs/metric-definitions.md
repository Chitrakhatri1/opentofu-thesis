# Metric Definitions

| Metric | Definition |
|---|---|
| Migration changes | Changed files and lines categorized by cause. |
| Migration effort | Active person-minutes spent completing and diagnosing the migration. |
| Command duration | Monotonic wall-clock time for a predefined command boundary. |
| Success rate | Successful trials divided by attempted trials under the predefined success condition. |
| Idempotence | Post-apply plan exits successfully and proposes no infrastructure changes. |
| Extensibility effort | Time, code additions, code changes, issues, and defects required for the second provider. |
